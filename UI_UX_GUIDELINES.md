# UI & UX Guidelines

## Purpose
Define a clean, consistent, and easy-to-use interface for the Hotel Reservation System.

## UI Principles
- Keep the interface simple and focused.
- Use clear spacing and strong visual hierarchy.
- Prefer rounded cards, soft shadows, and readable typography.
- Use consistent button styles for primary, secondary, and destructive actions.
- Keep colors calm and professional.

## UX Principles
- Reduce the number of steps needed to complete a task.
- Make booking, editing, and deleting actions easy to find.
- Show clear feedback for loading, success, and error states.
- Keep forms short and grouped by purpose.
- Ensure the experience works well on desktop and mobile.

## Layout Direction
### Auth Page
- Centered login/register card.
- Clear title and short supporting text.
- Simple form with visible validation.

### Admin Area
- Left sidebar navigation.
- Dashboard summary cards at the top.
- Tables with action buttons for edit/delete.
- Separate sections for users, rooms, reservations, payments, and logs.

### Guest Area
- Hero header with booking-focused message.
- Room cards with price, type, and availability.
- Booking flow should be quick and clear.
- Reservation history should be easy to scan.

## Component Standards
- Use consistent card spacing and border radius.
- Use badges for status labels like pending, confirmed, cancelled, and completed.
- Use modals for editing and booking actions.
- Use tables for admin data management.
- Use responsive grids for room listings and stats.

## Color Direction
- Primary: teal or deep green
- Secondary: slate or gray
- Success: green
- Warning: amber
- Danger: red
- Background: light neutral tones

## Typography
- Use a modern sans-serif font.
- Headings should be bold and slightly tighter in spacing.
- Body text should remain readable and moderate in size.

## Interaction Rules
- Buttons should have clear hover states.
- Inputs should have visible focus states.
- Empty states should guide the user on what to do next.
- Error messages should be short and specific.

## Responsiveness
- Stack layouts on smaller screens.
- Keep tables horizontally scrollable when needed.
- Make sidebar navigation mobile-friendly.
- Ensure forms remain usable on narrow screens.

## Outcome
The interface should feel:
- polished
- easy to navigate
- consistent
- fast to understand
- suitable for a hotel booking experience
